# 伴随 · 飞书交互 V2

2026-11-18 · 本地设计交付。示例数据，尚未替换当前运行的 MVP。

双击 [index.html](index.html) 即可打开本地原型，无需安装依赖或启动服务器。顶部可切换“可点击原型 / 十二屏图册 / 接入调研”。
